# 📖 Kairogram — Showcase & Official APK Download Portal

> **Where Spoken Words Meet Eternal Scripture.**  
> The next-generation biblical study companion with real-time sermon voice recognition, an authentic dual-page paperback Bible reader, interlinear Greek & Hebrew concordances, and zero-latency offline devotionals.

---

## 🌟 Key Features

- **🎙️ Real-Time Voice-to-Verse Recognition**: Listens to live sermons and spoken scriptures, classifies citations with sentence buffering, and pops up the verified verse card with zero delay.
- **📖 Dual-Page Paperback Spread**: Tailored for Android tablets (7" to 12"+) and landscape screens. Features authentic center spine stitching, drop-cap opening verses, and physical 3D page curl flips.
- **🏛️ Interlinear Strong's Lexicon**: Original Hebrew (*Westminster Leningrad Codex with Nikkud*) and Greek (*Scrivener 1894 Textus Receptus*) with word-by-word token concordance.
- **📜 Offline-First Devotionals Hub**: Bundled devotionals including *Open Heavens*, *Daily Manna*, *Rhapsody of Realities*, *Sunday School manuals*, and *MFM Devotionals*.
- **📝 Contextual Notes & Audio TTS**: Write personal sermon notes linked to verses and listen to scriptures read aloud via high-fidelity native TTS.

## 🚀 Live Preview & Deployment

- **Website**: Built with clean semantic HTML5, modern vanilla CSS (Obsidian Glassmorphism), and vanilla JavaScript.
- **Direct APK Hosting**: The production package `KairoGram.apk` is served directly from `/downloads/KairoGram.apk`.

### Deploying in 1-Click
This site has zero build steps and can be deployed instantly to:
- **Vercel**: Import this GitHub repository into Vercel and hit Deploy.
- **GitHub Pages**: Go to **Settings > Pages > Source > Deploy from Branch (`main` / root)**.
- **Netlify / Cloudflare Pages**: Drag and drop or connect repository with public root directory `./`.

---

## 💻 Local Development

To run the site locally:

```bash
# Using Python
python -m http.server 8090

# Or using Node.js npx
npx serve .
```

Open `http://localhost:8090` in your web browser.

---

## 📱 Installation on Android

1. Download `KairoGram.apk` from the site.
2. In Android, allow installation from unknown sources when prompted (*Settings > Security > Allow from this source*).
3. Tap **Install** and open the application.
4. Allow **Microphone Permission** to enable sermon voice recognition.
